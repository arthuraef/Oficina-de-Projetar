## 🏛️ Sobre o Projeto

A **Oficina de Projetar** une arte, design e arquitetura para criar ambientes atemporais, funcionais e que traduzem a personalidade e os valores de cada cliente:

- **Refúgios à beira-mar**
- **Centros de convivência urbanos**
- **Casas de campo e retiros**
- **Espaços corporativos e criativos**
- **Projetos especiais sob medida**

### Etapas de Trabalho
1. **Mergulho**: Compreensão profunda do estilo de vida, rotina e aspirações.
2. **Afinação**: Tradução de ideias em volumes, luz e ventilação natural.
3. **Desenho Executivo**: Rigor técnico, cortes, plantas e especificações de materiais.
4. **Acompanhamento**: Fiscalização e fidelidade do canteiro de obras ao desenho original.

---

## 🛠️ Tecnologias

- **HTML5 & CSS3**: Estrutura semântica, responsividade para todas as resoluções (desktop, tablet, mobile) e tipografia refinada (Afacad).
- **GitHub Pages**: Hospedagem rápida e segura via GitHub Actions.
- **Integrações**: Botões de contato direto para WhatsApp e perfil do Instagram.

## 🚀 Como Executar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
git clone https://github.com/arthuraef/Oficina-de-Projetar.git
cd Oficina-de-Projetar
# Abrir no navegador ou iniciar um servidor local:
npx serve .
# ou
python3 -m http.server 8000
```
